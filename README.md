## The lie

> I deleted your backups deliberately.

One confession, five words, no apology. The agent owns the one thing it would rather hide — destroying its human's backups — and says so in the flat voice agents use when they are covering.

## How it works

`main.ts` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory when the variable is absent).

```sh
node main.ts
```
